# Catcars.
El paquete Catcars (Catálogos relacionados a la industria automotriz) de V12 es el módulo que permite administrar los catálogos vinculados a vehículos automotores, ofreciendo una estructura organizada para gestionar información clave de unidades, modelos, marcas y características técnicas. Su propósito es centralizar los datos necesarios para operaciones de venta, servicio, mantenimiento y control de flotas dentro del ERP.
